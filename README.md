## 📦 Установка

### Windows (Steam / Epic Games Store)
1. Скачайте архив `Hela_Demo_Russian_v1.0_Release.zip`.
2. Распакуйте архив в любую папку.
3. Запустите файл `install_windows.bat`.  
   *(Скрипт автоматически найдет установленную игру в Steam или EGS, создаст резервную копию и скопирует файлы русификатора)*.
4. Запустите игру.

> **Ручная установка:** скопируйте файл `Hela-Windows.pak` в папку игры:  
> `...\Hela Demo\Hela\Content\Paks\`

### Steam Deck / Linux
1. Распакуйте архив на устройстве.
2. Откройте терминал в папке с распакованными файлами и выполните:
   ```bash
   bash install_linux.sh
   ```
3. Запустите игру через Steam.

---

## 🗑️ Удаление

* Запустите `uninstall_windows.bat` — скрипт удалит русификатор и восстановит оригинальные файлы.
* Либо в клиенте Steam: *ПКМ по Hela Demo → Свойства → Установленные файлы → «Проверить целостность файлов игры»*.
